# MineTool Manager

Уурхайн агуулахын багаж хэрэгслийн бүртгэл, олголт, буцаалтын интерфэйс. Одоогийн хувилбар нь бүх дэлгэцэд ижил жишээ өгөгдөл ашигладаг локал демо бөгөөд сервер эсвэл уурхайн мэдээллийн сантай холбогдоогүй. Демо өгөгдөл дэмжигдсэн хөтөчид `localStorage`-оор хадгалагдана.

## Хөгжүүлэлт

```bash
npm install
npm run dev
```

TypeScript шалгах: `npm run typecheck`

Үйлдвэрлэлийн build: `npm run build`

Камер уншигч ажилтны үнэмлэхний QR, Code 128/39/93, Codabar, EAN-13/8, UPC-A/E, ITF, Data Matrix, Aztec, PDF417 баркодыг дэмжинэ. Камерын зөвшөөрөл болон HTTPS (эсвэл localhost) шаардлагатай; төхөөрөмж, хөтчийн дэмжлэгээс шалтгаалан зарим формат уншигдахгүй байж болно.

## Багаж хайх, ангилал

Багажийн QR код болон шошго хэвлэх хэсэг байхгүй. Багажийг **Багажны бүртгэл**, **Багаж олгох**, **Багаж буцаах** хуудсуудаас нэр, ангиллаар хайж олно (код, эзэмшигчийн нэрээр ч хайна), ангилалаар нь шүүнэ.

Багаж бүртгэх/засах цонхонд ангилал нэмэх, хасах боломжтой. Ангилалын жагсаалт `localStorage`-д хадгалагдана. Багаж бүртгэлтэй ангилалыг хасах боломжгүй (эхлээд тэдгээр багажийн ангиллыг өөрчилнө), мөн хамгийн багадаа нэг ангилал үлдэнэ.

Багажийн зураг JPEG, PNG, WebP форматаар, нэг файлд 5 МБ хүртэл хэмжээгээр хүлээн авна. Эх зургийг IndexedDB-д, жагсаалтын WebP жижиг дүрсийг тусад нь хадгалдаг; localStorage-д зөвхөн зургийн түлхүүр бичигдэнэ. Зураг нь зөвхөн тухайн хөтөч, төхөөрөмж дээр үлдэх бөгөөд серверт илгээгдэхгүй, нөөцлөгдөхгүй. Хөтчийн хадгалалт цэвэрлэгдсэн эсвэл төхөөрөмж солигдсон бол зураг дахин боломжгүй.

PWA суурь манифест, аппликейшний дүрс болон өнгөний мета өгөгдөл нэмэгдсэн. Service worker, офлайн камер, backend холболт болон серверийн хадгалалт хэрэгжээгүй. Демо үйлдлүүд сервер рүү илгээгдэхгүй.
