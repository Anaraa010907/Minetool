# ⛏ Minetool — Уурхайн багажны бүртгэл

Утас болон компьютер дээр ажиллах (mobile-first, responsive) вэб апп. React + Vite.

## Боломжууд
- **Багаж** — бүртгэх, засах, хайх, төлвөөр шүүх (агуулахад / олгосон / засварт / актласан)
- **Олгох / Хүлээн авах** — ажилтны үнэмлэхний barcode-г уншуулж, багажны кодыг уншуулан олгоно. Буцаахдаа хэвийн/эвдэрсэн гэж тэмдэглэнэ (эвдэрсэн бол автоматаар засварт орно)
- **Засвар, үйлчилгээ** — засварт өгөх, дуусгах (хийсэн ажил, зардал), засварын түүх
- **Ажилчид** — нэр, албан тушаал, үнэмлэхний barcode
- **Barcode унших** — камер (Chrome Android гэх мэт BarcodeDetector дэмждэг хөтөч), USB скэнэр, эсвэл гараар бичих

## Ажиллуулах
```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```
Утсан дээр камер ашиглахад HTTPS шаардлагатай (deploy хийсний дараа эсвэл Codespaces-ийн port forward холбоосоор).

## Өгөгдөл
Одоогоор өгөгдөл хөтчийн `localStorage` дээр хадгалагдана (туршилтын горим).
Уурхайн database-тай холбохдоо `src/db/localAdapter.js`-тэй ижил `list / get / save / remove`
функцтэй шинэ adapter бичиж `src/db/index.js` дотор `adapter`-ыг солино — бусад код өөрчлөгдөхгүй.

## Бүтэц
```
src/
  db/            өгөгдлийн давхарга (adapter солих газар)
```
