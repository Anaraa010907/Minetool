# ⛏ Minetool — Уурхайн багажны бүртгэл

Утас болон компьютер дээр ажиллах (mobile-first, responsive) вэб апп. React + Vite.

## Боломжууд
- **Самбар** — бэлэн / олгосон / засварт багажны тоо, одоо олгогдсон багаж, сүүлийн үйл явдал
- **Багаж олгох** — ажилтны үнэмлэхний barcode, дараа нь багажны код уншуулж олгоно
- **Багаж буцаах** — багажны код уншуулж хүлээн авна. Эвдэрсэн бол автоматаар засварт орно
- **Бүртгэл** — багажны хүснэгт (хайлт, төлвөөр шүүлт, хуудаслалт), зурагтай бүртгэл, засах, устгах
- **Бусад** — Түүх ба тайлан (CSV экспорт), Засвар үйлчилгээ, Ажилчид
- **Barcode унших** — камер (Chrome Android гэх мэт), USB скэнэр, эсвэл гараар бичих

## Ажиллуулах
```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```
Утсан дээр камер ашиглахад HTTPS шаардлагатай (deploy хийсний дараа эсвэл Codespaces-ийн port forward холбоосоор).

## Өгөгдөл
Одоогоор өгөгдөл хөтчийн `localStorage`, багажны зураг `IndexedDB` дээр хадгалагдана (туршилтын горим).
Уурхайн database-тай холбохдоо `src/db/localAdapter.js`-тэй ижил `list / get / save / remove`
функцтэй шинэ adapter бичиж `src/db/index.js` дотор `adapter`-ыг солино — бусад код өөрчлөгдөхгүй.
